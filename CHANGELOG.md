## [1.0.0] - 2024-01-XX

### Added
- Automatic free game detection on Epic Games Store
- Secure login with session persistence
- Multi-game claiming in single run
- Exponential backoff retry mechanism
- Screenshot capture on errors
- Comprehensive logging system
- Discord webhook notifications
- Telegram bot notifications
- Docker and Docker Compose support
- GitHub Actions workflow for scheduling
- Unit and E2E tests
- Support for Windows, Linux, macOS, Raspberry Pi
- Anti-bot measures (browser fingerprints, stable selectors)
- Configuration via environment variables
- CLI commands for claiming and testing login
- Complete documentation and troubleshooting guides

- ⚡ Fast and reliable game claiming
